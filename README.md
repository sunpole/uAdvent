# uAdvent

**Материалы для подготовки детского рождественского адвента.**

В библиотеке собраны три рождественских плана чтения на русском языке. Каждый рассчитан на семь дней.

**Одна ссылка для другого чата — [открыть полные тексты всех планов](https://raw.githubusercontent.com/sunpole/uAdvent/main/library/index.jsonl).** В этом файле по одной записи на введение или день. Чат может прочитать всё сразу, найти фразу или повторно открыть отдельный день по его прямой ссылке. Для чтения в браузере есть [библиотека с оглавлением](https://sunpole.github.io/uAdvent/library/).

## Как пользоваться ссылкой в чате

Передайте ссылку вместе с задачей, например:

> Открой https://raw.githubusercontent.com/sunpole/uAdvent/main/library/index.jsonl и прочитай все три плана. Если текст обрезан, открой ссылки на отдельные дни. Найди задания о доброте, укажи план и день каждого примера и предложи своё задание для семейной встречи.

Для программного поиска скачайте [индекс JSONL](https://raw.githubusercontent.com/sunpole/uAdvent/main/library/index.jsonl). Каждая строка — одна запись с полями `plan`, `title`, `day`, `url` и `text`. Значение `null` в поле `day` обозначает введение с описанием и авторством. Соединение значений `text` одного плана в порядке записей даёт его исходный готовый текст, включая переводы строк.

## Как обновить библиотеку

Сначала соберите план по [инструкции для Windows](ИНСТРУКЦИЯ.md). В корне проекта выполните:

```powershell
py -3 "Программа/library.py"
py -3 "Программа/library.py" --check
py -3 -B -m unittest discover -s "Программа" -v
```

Проверьте изменения, добавьте сведения об источнике нового плана и отправьте в GitHub исходники, готовый план со сверкой и обновлённую папку `library`. После публикации ветки `main` GitHub Pages обновляет содержимое по тому же адресу.
