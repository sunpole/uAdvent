# uAdvent

**Материалы для подготовки детского рождественского адвента.**

uAdvent — репозиторий с исходными материалами для работы над рождественской программой для детей. На текущем этапе здесь собран **один семидневный план чтения** и подготовлена статическая стартовая страница. Готовая программа мероприятий, занятия и интерактивное приложение **пока не опубликованы**.

[Стартовая страница](index.html) · [Исходный план на YouVersion](https://www.bible.com/ru/reading-plans/29132-detiam-o-rozhdestve) · [Источники и права](THIRD_PARTY_NOTICES.md)

## Как открыть

- **Просмотр файлов:** откройте папку [data/001](data/001).
- **Стартовая страница:** откройте `index.html` в браузере. Она не требует установки зависимостей или сервера.
- **GitHub Pages:** адрес `https://sunpole.github.io/uAdvent/` указан в настройках репозитория. Для публикации страницы необходимо, чтобы Pages использовал ветку и каталог с `index.html`; факт работы опубликованного сайта следует проверить отдельно.
