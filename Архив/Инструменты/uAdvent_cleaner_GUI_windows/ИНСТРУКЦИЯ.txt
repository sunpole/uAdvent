ОЧИСТИТЕЛЬ UADVENT — ВЕРСИЯ С ГРАФИЧЕСКИМ ИНТЕРФЕЙСОМ
====================================================

Требования: Windows 10/11, Windows PowerShell 5.1, Python 3.9+.
Сторонние библиотеки Python НЕ требуются.

РАБОТА С ПРОГРАММОЙ
-------------------
1. Распакуйте архив так, чтобы файлы лежали вместе.
2. Дважды нажмите START_GUI.vbs — откроется окно без консоли.
   Если Windows блокирует VBS, дважды нажмите ЗАПУСТИТЬ_ОЧИСТКУ.cmd.
3. В окне нажмите «Выбрать папку…».
4. Выберите 001, 002 или родительскую папку 021_uAdvent.
5. Нажмите «Очистить и объединить».
6. Итог появится в cleaned внутри каждой распознанной папки-плана.

ПРИМЕР
------
Источник: C:\!CODE_CLUB\new 2026\021_uAdvent\001
Результат: C:\!CODE_CLUB\new 2026\021_uAdvent\001\cleaned\001_full.md
Отчёт:    C:\!CODE_CLUB\new 2026\021_uAdvent\001\cleaned\001_full_report.txt

Если выбрать C:\!CODE_CLUB\new 2026\021_uAdvent, будут обработаны
все ЕГО НЕПОСРЕДСТВЕННЫЕ подпапки, где находятся файлы .md.
Папка 002 содержит один большой исходный файл: корректность его
распознавания зависит от того, есть ли в нём строки «День N из M».
Если формат отличается, программа сообщит об ошибке и не тронет оригинал.

ИСТОЧНИКИ НЕ ИЗМЕНЯЮТСЯ. ПРИ ОШИБКЕ ЧИТАЙТЕ ОТЧЁТ И ЛОГ В ОКНЕ.

Дополнительный способ для опытных пользователей:
  py -3 clean_advent.py "C:\!CODE_CLUB\new 2026\021_uAdvent\001"
