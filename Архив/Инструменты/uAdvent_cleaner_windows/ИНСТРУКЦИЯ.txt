ОЧИСТИТЕЛЬ ПЛАНОВ uAdvent
========================

Нужен Python 3.9 или новее. Никаких библиотек устанавливать не требуется.

СПОСОБ 1. ДВОЙНОЙ ЩЕЛЧОК (Windows)
---------------------------------
1. Распакуйте архив в любую папку, не запускайте .cmd прямо из архива.
2. Дважды щёлкните ЗАПУСТИТЬ_ОЧИСТКУ.cmd.
3. В открывшемся окне выберите папку с файлами .md одного плана,
   например: C:\!CODE_CLUB\new 2026\uAdvent\data\001
4. Получите файл: data\001\cleaned\001_full.md
   И отчёт:        data\001\cleaned\001_full_report.txt

СПОСОБ 2. ПЕРЕТАСКИВАНИЕ ПАПКИ (Windows)
----------------------------------------
Перетащите папку 001 на файл ЗАПУСТИТЬ_ОЧИСТКУ.cmd.
Результат сохраняется в её подпапку cleaned.

СПОСОБ 3. КОМАНДНАЯ СТРОКА
--------------------------
python clean_advent.py "C:\путь\к\uAdvent\data\001"

Обработать сразу несколько планов в соседних папках 001, 002, ...:
python clean_advent.py "C:\путь\к\uAdvent\data"

Сохранить в указанное место:
python clean_advent.py "C:\путь\к\uAdvent\data\001" --output "C:\готово\План.md"

ЧТО ОСТАНЕТСЯ В ИТОГОВОМ MARKDOWN
---------------------------------
- Название и исходное описание плана с авторством (если есть отдельная обложка).
- Все дни по порядку.
- Основные тексты, задания, молитвы, цитаты и ссылки на Писание.

ЧТО БУДЕТ УДАЛЕНО
------------------
- Навигация, номера меню, кнопки и баннеры приложения.
- Повторное описание плана после каждого дня.
- Подвал сайта YouVersion.

БЕЗОПАСНОСТЬ
------------
Исходные файлы .md никогда не перезаписываются.
Скрипт создаёт новый файл в cleaned и отдельный отчёт проверки.
Если день отсутствует или структура страницы отличается, в отчёте появится
предупреждение. Результат в таком случае нужно проверить вручную.
Скрипт не переписывает формулировки автора.

ВАЖНО
------
Правила проверены под текстовые копии страниц YouVersion, аналогичные
плану ДЕТЯМ о РОЖДЕСТВЕ. Неизвестная структура страниц может потребовать
дополнительных правил, о чём сообщает отчёт.
