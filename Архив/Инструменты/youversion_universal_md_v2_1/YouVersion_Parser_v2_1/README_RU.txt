YouVersion -> один Markdown-файл. Версия 2.1 для Windows.

КОРОТКО:
1. Распакуйте сюда, например:
   C:\!CODE_CLUB\new 2026\021_uAdvent\Parser_v2_1\
2. Дважды щёлкните START.cmd.
3. Вставьте ссылку на план, например:
   https://www.bible.com/ru/reading-plans/22246
4. Итоговый файл YouVersion_22246_НАЗВАНИЕ.md будет рядом со скриптом.

Особенности:
- Подходит для планов на 3, 7, 21, 365 и другое число дней (до 1000).
- Сам определяет количество дней и использует ссылки на реальные дни.
- Русские и английские обозначения дней и разделов поддерживаются.
- Сохраняет заголовки, видимые абзацы, вопросы, молитвы,
  ссылки на библейские чтения (названия чтений), последовательность дней.
- Никакого пересказа/перевода/дописывания; только служебные заголовки
  Markdown и сведения об источнике. Пробелы и переносы нормализуются.
- Убирает элементы интерфейса сайта; по ссылкам на чтения не переходит
  для скачивания полных библейских глав.
- Обложка в Markdown — внешняя ссылка на картинку, не скачанный файл.
- При ошибке итоговый файл НЕ создаётся и уже существующий не заменяется.
- Успешные дни кэшируются в скрытой папке .youversion_cache_...
  для возобновления. Чтобы загрузить заново, удалите папку кэша.

Безопасность:
- HTTPS-проверка сертификатов НЕ отключается.
- Если urllib Python не доверяет цепочке сертификатов, скрипт пробует
  системный curl.exe Windows, тоже с включённой HTTPS-проверкой.
- Если оба способа не могут проверить сертификат, скрипт честно сообщит
  об ошибке. Проверьте дату и часовой пояс Windows, системные
  сертификаты, перехват HTTPS антивирусом/прокси.
- Внешние библиотеки, Playwright и установка браузера НЕ нужны.

Ограничения:
- Некоторые страницы Bible.com могут менять разметку или ограничивать
  автоматические запросы. Проверка на реальном ПК и всех типах планов
  необходима. Проверки полноты всех текстов по сайту не было.
- Текст, существующий только внутри изображений или видео, не извлекается.
- Сведения о параграфах/начертаниях HTML превращаются в текстовые абзацы MD.
- Текст авторских планов может быть защищён авторским правом:
  используйте выгрузку с учётом прав издателей.
