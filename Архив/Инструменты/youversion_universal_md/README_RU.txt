YouVersion — универсальный экспорт плана в ОДИН Markdown-файл.

Запуск на Windows:
1. Установить Python 3, если его нет (https://www.python.org/downloads/windows/).
2. Распаковать архив.
3. Запустить START.cmd и вставить ссылку на любой публичный план Bible.com.
4. Дождаться сообщения «ГОТОВО»; рядом появится YouVersion_ID_Название.md.

Подходят ссылки на план и на любой день внутри плана, например:
https://www.bible.com/reading-plans/29132/day/2?segment=0
https://www.bible.com/reading-plans/158-the-bible-in-a-year

План получает число дней из своего описания. Нет ручного изменения числа дней.
Для каждого дня сохраняется текст материала и список библейских ссылок, как они
показаны на странице плана. Полный текст глав по ссылкам Scripture не загружается:
ссылки на отдельные переводы Библии — это самостоятельные страницы.

Текст внутри изображений/видео не извлекается. Картинка обложки вставляется в
Markdown по URL; сам графический файл не скачивается.

В случае ошибки НЕТ итогового «полного» файла с пропущенными днями.
Повторный запуск продолжит с уже сохраненных данных в скрытой папке кеша.
Текст не исправляется, не переводится, не перефразируется.
Проверка фактической полноты на всех возможных планах невозможна: YouVersion
может менять верстку, и некоторые планы содержат нетекстовые материалы.

Программа читает открытые публичные страницы, без авторизации и обхода защиты.
Соблюдайте права издателей при дальнейшем использовании текста.
