YouVersion -> один Markdown-файл — версия 2.2

КАК ЗАПУСТИТЬ
1. Распакуйте YouVersion_Parser_v2_2 в папку проекта:
   C:\!CODE_CLUB\new 2026\021_uAdvent\YouVersion_Parser_v2_2\
2. Дважды щёлкните START.cmd.
3. Введите ссылку на любой публичный план, например:
   https://www.bible.com/ru/reading-plans/17399
4. При успехе один файл YouVersion_17399_Название.md появится
   в той же папке рядом со START.cmd.

ИЗМЕНЕНИЯ ПО СРАВНЕНИЮ С V2.1
- Парсер распознаёт надпись «День 2 из 7», даже если сайт
  разделил её на несколько вложенных HTML-блоков.
- Если заголовка в HTML нет, ищет последовательность ссылок
  на дни и раздел «Священное Писание»; ненадёжные случаи
  по-прежнему считаются ошибкой, без выдумывания текста.
- Показывает полный адрес первого дня, найденный на странице
  плана, включая обязательную часть названия в URL.
- При неудаче создаёт файл YouVersion_НОМЕР_DIAGNOSTICS.txt
  с адресами и извлечёнными строками; по нему можно точно
  выяснить, что реально вернул сайт.
- Не использует Playwright, не ставит внешние библиотеки.
- Не отключает проверку SSL-сертификатов.
- Кэш предыдущей версии НЕ используется, чтобы не переносить
  старые ошибки в новый результат.

ТОЧНОСТЬ И ОГРАНИЧЕНИЯ
- Берётся текст общедоступных страниц каждого дня, без
  перефразирования и генерации новых материалов.
- Количество дней определяется автоматически; лимит 1000.
- Ссылки на чтения Библии сохраняются как названия отрывков.
  Полный текст глав, открываемых по другим ссылкам,
  не скачивается.
- Пробелы и переносы HTML приводятся к читаемым абзацам MD;
  посимвольная идентичность исходному HTML не обещается.
- Содержимое картинок и видео не преобразуется в текст.
- Не создаёт или не заменяет итоговый .md, пока не получены
  ВСЕ дни. Успешные дни сохраняются в кэше для возобновления.
- Интернет и установленный Python 3 необходимы.
- Код проверен на искусственных HTML-страницах, но полная
  реальная проверка на компьютере автора плана не выполнялась.

ЕСЛИ ОПЯТЬ ОШИБКА
Пришлите созданный файл YouVersion_НОМЕР_DIAGNOSTICS.txt,
не нужно присылать весь скрипт: по тексту файла можно увидеть,
какую разметку фактически возвращает Bible.com.

Используйте материалы планов с учётом авторских прав издателей.
