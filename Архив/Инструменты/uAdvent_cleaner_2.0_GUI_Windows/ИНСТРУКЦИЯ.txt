uAdvent Cleaner 2.0 — очистка и объединение планов YouVersion
=============================================================

НАЗНАЧЕНИЕ
  Создаёт один Markdown-файл из содержимого ВСЕХ дней одного плана.
  Работает со следующими видами исходных данных:
  • 001: обложка и 7 дней в восьми отдельных файлах .md;
  • 002, 003: обложка и 7 дней внутри ОДНОГО длинного файла .md;
  • смешанный вариант: разные дни/страницы в нескольких .md.

КАК ЗАПУСТИТЬ В WINDOWS
  1. Убедитесь, что Python 3.9+ установлен (проверьте командой py -3 --version).
  2. Распакуйте ВСЕ файлы этого архива в папку
       C:\!CODE_CLUB\new 2026\021_uAdvent\uAdvent_cleaner_windows
     Если старая версия уже там — замените её файлами из этого архива.
  3. Дважды нажмите START_GUI.vbs — появится графическое окно.
     Если VBS запрещён политикой Windows, запустите ЗАПУСТИТЬ_ОЧИСТКУ.cmd.
  4. Кнопкой «Выбрать папку...» укажите:
       C:\!CODE_CLUB\new 2026\021_uAdvent
     для всех планов сразу, ИЛИ вложенную папку 001, 002, 003 для одного плана.
  5. Нажмите «Очистить и объединить».

РЕЗУЛЬТАТЫ
  При выборе общей папки появятся файлы:
    001\cleaned\001_full.md
    001\cleaned\001_full_report.txt
    002\cleaned\002_full.md
    002\cleaned\002_full_report.txt
    003\cleaned\003_full.md
    003\cleaned\003_full_report.txt

  Содержимое Markdown-файла:
    # Название плана
    ## О плане
    Оригинальное описание и авторские сведения
    ## День 1
    Заголовок, текст, задания, вопросы, молитвы, ссылки на Писание
    ...
    ## День 7
    ...

БЕЗОПАСНОСТЬ
  • Исходные .md не изменяются и не удаляются.
  • Каталог cleaned не сканируется повторно.
  • При повторном запуске обновляется только созданный итоговый файл и отчёт.
  • Если нет дней, файл результата не создаётся.
  • Дубликаты/пропущенные дни указываются в отчёте.
  • Если другие шаблоны YouVersion отличаются, проверьте предупреждения и результат.

ЗАПУСК ИЗ POWERSHELL (необязательно)
  py -3 "C:\!CODE_CLUB\new 2026\021_uAdvent\uAdvent_cleaner_windows\clean_advent.py" "C:\!CODE_CLUB\new 2026\021_uAdvent"

Требования: Windows 10/11, Python 3.9+, PowerShell 5.1, стандартные
Windows Forms. Никаких дополнительных библиотек устанавливать не нужно.
