# Рабочая тетрадь

В эту тетрадь можно писать своими словами. Первую запись удобно сделать прямо в разговоре. Когда чат подготовит обновлённую версию, сохраните её у себя. Чтобы продолжить в другом чате, передайте ему эту тетрадь вместе с файлом «Начать чат.txt».

## С чего продолжить

Пока здесь нет записей.

## История работы

Для каждой темы можно завести свой заголовок. Запись может занимать одну строку. Если важна точная формулировка, сохраните её в кавычках и отметьте, чьи это слова. Сюда же удобно возвращать ссылки на конкретные дни планов и оставлять вопросы, которые пока хочется подержать открытыми.
