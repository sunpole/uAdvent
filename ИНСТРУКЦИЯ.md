# uAdvent · планы чтения YouVersion

Двойной щелчок по **[Собрать план.cmd](<Собрать план.cmd>)** собирает один план из вручную скопированных страниц. Программа работает локально. На этом компьютере всё для запуска уже установлено.

## Готовые планы

| План | Готовый текст |
|---|---|
| ДЕТЯМ о РОЖДЕСТВЕ | [Открыть 7 дней](<Готовые планы/001/План.md>) |
| Весело и ярко: празднуем Рождество каждый день | [Открыть 7 дней](<Готовые планы/002/План.md>) |
| История Рождества за 7 дней: праздничные чтения для всей семьи | [Открыть 7 дней](<Готовые планы/003/План.md>) |

## Как собрать новый план

1. Откройте **Исходники**. Создайте внутри папку с названием нового плана, например `Рождество с семьёй`.
2. Откройте в браузере русскую страницу с описанием плана. Нажмите **Ctrl+A**, затем **Ctrl+C**. Вставьте в Блокнот через **Ctrl+V**. Так же скопируйте страницу каждого дня целиком, включая меню сверху и строку © YouVersion внизу.
3. Можно вставлять все страницы **в один файл**. Между страницами нажимайте **Enter**, чтобы первая строка новой страницы начиналась отдельно. Можно сохранить **по файлу на страницу**. Подойдут оба варианта и их сочетание. Сохраните файлы в созданную папку как обычный текст **UTF-8** с расширением `.txt` или `.md`. Имена и порядок файлов произвольные. В одной папке держите один план.
4. Дважды щёлкните **Собрать план.cmd** и выберите папку нового плана. После сборки нажмите **Да**, чтобы открыть папку с результатом.
5. Откройте **План.md** в Блокноте. В нём весь план подряд. Рядом находится **Сверка.txt**. Если хочется проверить фразу, в сверке указаны исходный файл и номера строк каждого фрагмента.

## Что переносится в текст

Сначала идут название, оригинальное название, если оно отличается, продолжительность, описание и сведения об издателе. Следом идут дни по номерам. В каждом сохранены исходный заголовок «День N из M», чтение, задания, молитвы, раздел «Священное Писание» и все скопированные ссылки на стихи. Отдельное сообщение YouVersion о недоступных отрывках сохраняется в том месте, где оно встретилось. В плане 002 такое сообщение есть в шестом дне.

Программа копирует выбранные строки целиком, вместе с пробелами, табуляциями, пустыми строками, эмодзи и исходными переводами строк. Заголовки Markdown, нумерацию от себя и разделители она не вставляет. Меню сайта, кнопки, рекомендации других планов и повторные сведения об одном плане остаются в исходниках. Если отдельная обложка отсутствует, название, описание и авторство берутся из блока «Об этом плане» на страницах дней.

Проверка относится к тексту, который вы **вставили и сохранили**. Если в копии указана только ссылка на стих, в готовом тексте будет эта же ссылка. Изображения, содержимое ссылок и пропуски внутри скопированного абзаца программа восстановить не может.

## Если сборка остановилась

- **Пропущен или повторяется день.** Добавьте страницу недостающего дня или уберите лишнюю копию из рабочей папки.
- **Названия, описания или издатели различаются.** Проверьте, что все файлы относятся к одному плану и одному языку. Исходная и переводная версии названия на одной странице допустимы.
- **Не распознана граница страницы.** Откройте указанный файл у строки из сообщения. Проверьте, что скопировали верхнее и нижнее меню, а соседние страницы начинаются с отдельных строк. Если полная копия выглядит иначе, сохраните её как пример нового шаблона для доработки программы.
- **Проблема с кодировкой.** В Блокноте выберите «Сохранить как» и укажите UTF-8.

При ошибке программа не выдаёт новый файл. Предыдущие сборки остаются в **Готовые планы**. При повторном запуске с теми же файлами откроется тот же результат. Если текст или сверка изменились, рядом появится новая папка с номером в скобках.

## Где что лежит

| Путь | Назначение |
|---|---|
| `Собрать план.cmd` | Обычный запуск в Windows |
| `Исходники/<имя плана>/` | Рабочие копии страниц. В 001 есть пример раздельных файлов, в 002 и 003 — общего файла |
| `Готовые планы/<имя плана>/` | Готовый текст и сверка с исходником |
| `Программа/cleaner.py` | Действующий очиститель и окно выбора папки |
| `Программа/test_cleaner.py` | Проверки на трёх сохранённых примерах и повреждённых копиях |
| `Архив/Инструменты/` | Предыдущие программы очистки и попытки загрузки с сайта |
| `Архив/Прежние результаты/` | Старые папки 001–003 вместе с исходными копиями и результатами прежних программ |

## Для того, кто будет дорабатывать программу

Нужен Python 3.10 или новее. Для окна Windows используется встроенный компонент tkinter. Пакеты из интернета устанавливать не требуется. Команды запускаются из корня проекта.

```powershell
py -3 "Программа/cleaner.py" "Исходники/001"
py -3 "Программа/cleaner.py" "Исходники/002/002-0001.md"
py -3 -B -m unittest discover -s "Программа" -v
```

При запуске с отдельным файлом имя папки результата берётся из имени файла, при запуске с папкой — из имени папки. Параметр `--вывод "путь"` задаёт другую папку для результатов.

Очиститель распознаёт структуру полных русскоязычных копий, представленных в архивных примерах. Распознавание и извлечение разделены. Для распознавания используются служебные строки в ожидаемых сочетаниях. Для записи берутся целые диапазоны строк источника. В начале файла допускается служебная метка UTF-8. Сверка содержит контрольные суммы SHA-256 входных файлов и результата.

При добавлении нового вида страницы сохраните исходный пример, отметьте вручную границы полезного текста и добавьте проверку результата по байтам. Сохраните проверки для двух исходных способов копирования. Особенно важны строки авторского текста, которые совпадают с надписями кнопок, несколько пустых строк подряд и пробелы в конце строк.
